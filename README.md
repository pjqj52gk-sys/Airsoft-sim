# AIRSOFT CUSTOM STUDIO v0.4

エアガンとパーツの画像を、実寸比率で組み合わせるローカルの2D外観シミュレーター。

## 起動

Node.js 22.18以上（検証環境: 24.13）で実行します。

```powershell
npm ci
npm run dev
```

表示された Local URL をブラウザーで開きます。

```powershell
npm run build
npm start
npm run typecheck
npm test
```

## v0.4 の追加機能

- **切り出し**: 画像の対角2点を選び、範囲を切り出します。元画像を残し、独立したパーツとして追加することもできます。回転・反転・実寸比率・配置を維持します。
- **パース補正**: 斜め向きの立方体を、Y字の中心と3つの枝先で画像へ合わせます。中心は全体移動、枝先は幅・奥行き・高さを調整します。現在の3方向から直角の箱を再計算し、「パースの強さ」で遠近感を調整します（0%は平行投影）。画像と一緒に回転し、正面にして平面化できます。平面化後の縦横比には計算した面の比率を使います。4点だけでは写真の焦点距離は一意に決まらないため、強さを調整して合わせてください。補正できるのは選択した平面です。見えない面は生成せず、実寸は2点校正で確認します。
- **背景透過のプレビュー**: 許容差を調整し、結果を確認して適用します。キャンセルでは編集内容を変更しません。
- **2点で実寸合わせ**: 画像中で長さが分かる区間の2点を選び、その区間のmmを入力します。画像の余白を含めた縮尺を計算します。
- **パーツライブラリ**: 画像・実寸・価格・URLを登録し、別のビルドへ複製できます。追加したパーツの変更は登録元へ影響しません。
- **複数ビルドの保存・比較**: 保存名を付けて状態を保存し、編集中のビルドと同じ縮尺で比較できます。開く前の状態にはUndoで戻れます。
- 保存したビルドとパーツは個別にJSONへ書き出せます。登録データの削除には2回の操作が必要です。
- IndexedDBをバージョン2へ移行します。既存の自動保存は維持されます。

## 使い方

1. 本体の横向き画像を読み込み、画像の横幅に対応する実寸を入力します。画像はドラッグで移動できます。
2. パーツ画像を追加し、同様に横幅の実寸を入力します。数字は Enter またはフォーカスを外して確定します。
3. ドラッグ、矢印キー（1mm）、Shift + 矢印（10mm）で配置します。回転、左右反転、前後順、複製、表示を調整できます。パーツの「本体に固定」は、本体の移動・回転・反転へ追従させます。固定したパーツも個別に配置を調整できます。
4. 「本体のみ」と「カスタム」を切り替えて比較します。
5. 自動保存はブラウザーの IndexedDB に保存されます。「保存」で画像を内包するJSONをバックアップし、PNGで透過画像を書き出せます。

「デモのビルドを試す」から操作を確認できます。デモは説明用イラストで、特定商品の寸法や仕様を再現したものではありません。

## データと既存機能

- 画像はPNG / JPEG / WebP / GIF、1ファイル15MBまで。長辺2000pxに縮小し、アニメーション画像は静止画になります。
- 最大60レイヤー、履歴は20操作分。画像の読込・透過・書き出しはブラウザー内で実行し、サーバーにアップロードしません。
- 左上の色に近く、外周とつながる領域だけを背景透過します。複雑な背景には適しません。許容差を調整し、元画像への復元やUndoが使えます。
- 従来のV1プロジェクトJSON、パーツ単体JSONを読み込めます。V1の保存された表示幅を使って座標を変換します。表示幅が欠落した古いデータは位置の調整が必要なことがあります。
- `/legacy` に元のエディターを保存しています。パース補正と切り出しは新画面にも統合済みです。旧画面で書き出したJSONを新画面で読み込んでください。旧画面はV2 JSONの読込には対応していません。
- IndexedDBの保存先はブラウザーとURL（ポートを含む）ごとに分かれます。ブラウザーデータの削除に備えてJSONを保存してください。
- 参考価格は手入力、合計は本体を除く全パーツ（非表示を含む）です。楽天の商品価格と公式カタログの公開価格は画像の追加時に取り込み、手入力で修正できます。公式カタログの写真は検索から選択して追加できます。

画像の余白、撮影角度、パースにより見え方が変わります。取付可否・干渉・性能は判定しません。

### 画像のドラッグ＆ドロップとホイール操作

- 画面に画像ファイルをドロップすると追加できます。初期画面では最初の1枚を本体、残りをパーツとして追加します。
- 左の本体エリアへ1枚ドロップすると本体画像を入れ替えます。パーツと本体の実寸設定は保持されます。
- パーツ追加エリア・キャンバス・ヘッダーなどへは複数画像をまとめて追加できます。
- 本体・パーツともドラッグで移動できます。旧保存データの移動ロックは無視します。新しい本体への固定はJSON・自動保存・ビルド保存で保持します。
- ホイールは表示のズームイン・ズームアウト専用です。画像の実寸(mm)は変更しません。
- ズームは編集履歴に含めません。本体の移動・回転・反転に付随するパーツの移動は1回のUndoで戻せます。本体画像の切り出し・差し替えではパーツを移動しません。

### パーツ検索

- 「パーツを検索」から公式カタログ176件（4メーカー）と登録パーツを検索できます。名前・メーカー・カテゴリー・寸法の絞り込みに対応します。
- 東京マルイ公式ページを2026-11-02に確認した検索用スナップショットです。寸法掲載は10件。数値がない商品は「公式ページに未掲載」と表示し、推測値を記載しません。
- 写真候補は公式の商品ギャラリー1,123枚です。宣伝用のOG画像とメニュー用サムネイルを取り込み候補から除き、掲載された元画像を使います。画像をクリックすると拡大でき、解像度を確認して「この写真を追加」で取り込めます。出典の商品URLを購入メモへ保持します。全長が掲載されている場合は2点で実寸合わせを開き、全長を初期入力します。画像の余白や構図が異なるため、全長を画像横幅として直接適用しません。
- カタログ外の商品用にWeb画像検索・寸法検索へのリンクを用意しています。一般Web検索結果をアプリ内へ取得する機能ではありません。
- 画像は `/api/part-image?id=...&photo=...` 経由で公式から取得します。任意URLは受け付けず、カタログ内の公式ホスト・パスと画像形式を検証し、12秒・5MBを上限にしています。取得失敗時は公式ページから保存して追加できます。独自のAPIキーは不要です。
- 商品画像の権利は各権利者に帰属します。配布物に画像ファイルを同梱せず、元画像は公式から取得します。

### ショップURLと購入導線

- 「パーツ検索 → ショップURL」で公開HTTPSの商品ページを入力します。JSON-LD Product、OGP、商品寸法の表を読み、写真を選択して追加できます。ショップごとの公開形式・アクセス制限により取得できない場合があります。
- 全長と梱包サイズを分けて表示し、梱包サイズは実寸校正に使いません。画像URL・画像ファイルの追加も可能です。写真の取得と編集には権利者の利用許諾が必要です。公開前に既存カタログ写真を含め利用条件を確認してください。
- Amazonの商品URLは購入リンクとして登録します。Amazonのアソシエイト向けコンテンツには加工・画像保存などの制約があるため、商品ページやCDNから画像をシミュレーターへ取り込む処理には接続しません。編集用は自分の写真や別途許諾を得たメーカー素材を使います。
- 「選択中のパーツに購入リンクを設定」で、画像を変えずに商品URLだけを関連付けられます。「購入リスト」から各ショップを開けます。
- 取得処理は接続直前にDNS結果を確認し、公開IPv4へ固定してHTTPSで接続します。ローカル・プライベートIP、認証付きURL、非標準ポートを拒否し、転送先も再検証します。ページは展開後3MB、画像は4MB、処理は約16秒までです。HTML内のJavaScriptは実行しません。

### 収益化の準備

- まず「シミュレーション → 購入リスト → 商品ページ」の導線を整えます。広告ネットワークのスクリプトは未導入です。
- Amazonアソシエイトの承認済みIDを `lib/commerce.ts` の `monetization.amazonAssociateTag` に設定すると、Amazon.co.jpのASIN付き購入先をサイト運営者のタグ付きリンクへ変換します。初期値は空で、架空IDによる収益化は行いません。設定値は公開される識別子で、API秘密鍵をここへ置かないでください。
- 生成した広告リンクには `rel="sponsored noopener noreferrer"` と広告ラベルを付けます。広告リンクがある場合はアフィリエイト表示を出し、運営者IDが設定された場合にAmazonアソシエイトの表明を出します。編集画像と出典URLは変えません。
- Amazonの検索・広告カードを自動提供する段階では、Creators APIの登録・認証情報と表示条件への対応が別途必要です。今回のURL入力機能はAmazon公式API連携の代替ではありません。
- 広告枠は将来、編集を妨げない購入リストや公開ビルド詳細へ配置する方針です。公開ビルド・利用分析・広告配信・同意設定は今後の実装対象です。
- 公式参照: [Amazonアソシエイト規約](https://affiliate.amazon.co.jp/help/operating/policies)、[Creators API](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/introduction)。


### 楽天市場検索

パーツ検索は楽天市場のカテゴリ検索から開きます。M4カービンのSVGシルエット上に取り付け位置を表示します。光学機器・マズル・グリップ・ストック・ハンドガード・マウント・ライトの位置ラベルから小分類を選ぶと、対応する語で検索します。画像追加時は光学機器・グリップなどの分類も引き継ぎます。楽天市場で、商品画像・価格・ショップ・購入リンクを表示します。検索対象は「サバイバルゲーム・トイガン」（ジャンルID 213684）に限定し、一般的な検索語でも他ジャンルの商品が混ざらないようにしています。「画像を選んで追加」で商品ページの写真を取得し、写真を選択して編集画面へ追加できます。商品名・検索時の価格・購入リンクも引き継ぎます。商品ページを取得できない場合は、APIが返した検索画像をそのまま選べます（小さい画像と表示）。寸法は写真の幅から推測せず、取得できた公表値がある場合だけ寸法合わせに引き継ぎます。画像の権利・利用条件は販売店等の条件を確認してください。

`.env.example` を `.env.local` にコピーし、楽天 Developers の `RAKUTEN_APPLICATION_ID` と `RAKUTEN_ACCESS_KEY` を設定します。`RAKUTEN_AFFILIATE_ID` は任意です。APIが返すアフィリエイトリンクには広告表記を付けます。許可サイトの指定が必要な場合は `RAKUTEN_ALLOWED_ORIGIN` に登録済みサイトの Origin を指定します。キーは NEXT_PUBLIC_ にせず、Git に追加しないでください。Vercel では同じ名前をプロジェクトの環境変数に設定します。

公式仕様: https://webservice.rakuten.co.jp/documentation/ichiba-item-search （20260701）
クレジット: https://webservice.rakuten.co.jp/guide/credit

読み込み・画像処理中は、BBローダーからマガジンにBB弾を補充するSVGアニメーションを中央に表示します。端末の動きを減らす設定では静止表示になります。

### 公式カタログの参考価格

4メーカーの公開価格を更新スクリプトで取得します。カタログに希望小売価格／公式販売価格と税区分を表示し、画像を追加すると参考価格と購入リストへ引き継ぎます。税別の希望小売価格は10%で税込換算（円未満四捨五入）し、表示にも「税込換算」を付けます。公式APIに税区分のない価格は「税区分未確認」と表示し、掲載額のまま保持します。参考価格は確認日時点の値で、実売価格・送料は購入先で確認します。仕様別の価格差がある場合は価格帯を表示し、特定仕様を選べないため取り込み時の参考価格は手入力とします。掲載のない価格は推測しません。

### 販売店画像の解像度

楽天の商品ページでは、共有用OG画像だけでなく商品ギャラリーのmicrodataを取得します。同じ商品の画像ファイル名に対応する説明画像も候補に含め、ヘッダーの広告・関連記事の画像を除きます。ショップが公開する拡大画像属性やsrcsetがあれば、そのURLを優先します。画像URLのサイズ指定を推測して書き換えることはしません。

商品ページ取得時に最大8枚を3並列・合計8秒まで検査し、実際の画素数が多い順で選べます。取り込み前に各候補の解像度と、小さい画像の案内を表示します。元画像自体が小さい場合は解像感を復元できないため、別の写真や画像URL・ファイルから追加してください。すでに追加済みの画像は自動置換せず、再度検索して取り込みます。
