# みんなのカスタム

`/community` で公開作例を検索し、構成をコピーしてエディターで試せます。銃種・登録価格の合計・タグ・商品名で絞り込めます。コピー前の下書きはIndexedDBのライブラリに保存します。公開はスナップショットで、その後の編集には連動しません。

## 保存先

NeonのVercel Marketplace連携を使用します。サーバー専用の `DATABASE_URL` を設定してください。`NEXT_PUBLIC_` は付けません。初回API呼び出しで `community_builds` とインデックスを作成します。接続が未設定でもビルドは通り、画面は準備中を表示します。

本番はNeonの標準データベース、ローカルは同じNeonプロジェクト内の別データベース `airsoft_development` を使用しています。ローカル接続先はGit対象外の `.env.development.local` に保存しています。プレビューはMarketplaceのブランチ作成を有効にしています。`vercel env pull` を使う際も、ローカルの上書き設定を保持してください。

## 公開と管理

- 初期版はアカウント不要。ブラウザーごとのランダムな管理キーをHttpOnly / SameSite=Lax Cookieに保存し、DBにはSHA-256ハッシュだけ保存します。本番CookieはSecureです。
- 同じブラウザーの「自分の投稿」から取り下げ・再公開できます。Cookieを削除した場合や別ブラウザーでは管理できません。ユーザー登録・ログインやプロフィールはまだありません。
- 取り下げた投稿は一覧・共有リンク・詳細APIから非公開になり、所有者だけ閲覧できます。管理キーはAPIレスポンスに含めません。
- 表示中のレイヤーだけ公開します。非表示レイヤー、編集前の元画像、復元用の余白情報は送信・保存しません。画像はWebPへ変換し、サーバーでも画像の実体・寸法を検査して再エンコードします。
- 投稿本文は3.5MB、レイヤーは60件、タグは6個まで。1ブラウザーからの新規公開は1時間5件まで。同じリクエストIDの再送は重複登録しません。この制限はアカウントやIPによる総量制限ではありません。
- 初期版は軽量化した画像とプレビューをDBに保持します。投稿数が増えたら画像をBlob等へ移し、認証・通報・運営による管理機能を追加してください。

## 確認

`npm test` / `npm run typecheck` / `npm run build`。画像や管理キーを含むログは出力しません。DB接続情報・Cookie・`.env*` はコミットしないでください。
