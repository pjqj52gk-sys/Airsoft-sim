# 本体の方式・世代照合

2026-11-05更新。

## P90プラスの不具合

P90プラスの登録画像URLは公式ページの専用ギャラリーと一致していた。一方、カタログ名の末尾にある「【電動ガンプラス】」が商品名照合の一部となり、「P90プラス」だけの販売店名では通常P90が部分一致していた。表示注記を識別名から分離し、PLUS・＋表記も正規化した。プラス版の候補がなくても通常版へ置き換えない。

## 共通判定

- 本体の動力方式・シリーズ・対象年齢・世代を名前の一致度とは別に検証する。
- 電動、ガス、エアコッキングを区別。次世代、ハイサイクル/HC、プラス、BOYS、ライトプロ、電動ハンドガン、電動コンパクト、電動ブローバック/フルオート、Rシリーズ、ミニ電動も識別する。
- ガスではブローバック、固定スライド、CO2などの明示的な条件を照合する。既知の対象年齢10/14/18才、10禁/18禁等の表記、GenとVの世代も比較する。
- 東京マルイは公式URLの分類とシリーズを根拠にする。他メーカーの本体も、カタログ名・シリーズに公開された方式と世代を検証する。
- JAN・メーカー型番が一致しても、方式や世代に矛盾があれば不採用。商品検索と販売店ページの一方に矛盾がある場合も、情報の統合後に再確認する。
- H&Kやコルト等の接頭語・表示注記が違うだけの同系列商品を比較し、方式が特定できないときに長い商品名を優先しない。
- 部品のAEG/GBB適合判定、色違い、レプリカ、セット、アクセサリーの既存判定も維持する。
- カタログ側の判定情報はWeakMapにキャッシュし、販売店名の解析は1回の照合で1度だけ実施する。

## 検証

P90/TR/プラス/レン、G36Cの4系列、同名の方式違い、10才用/18才用、世代違い、JAN・型番の矛盾、カタログに正しい版がない場合、検索と販売店ページが矛盾する場合を回帰テスト化。登録済み東京マルイ本体の全項目について、公開名・シリーズを与えた照合が他商品を選ばないことも確認する。

方式の表記がない、未登録の通称、カタログに分類情報がないなどのケースまで完全一致を保証するものではない。確定できない場合は公式写真へ自動置換せず、販売店の写真や公式カタログから手動で選択する。
